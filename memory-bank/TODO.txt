# EU4dll 開発 TODO

## 現在の状態（2026-11-22）

- 対象は Linux x86-64 版 EU4 v1.37.5。
- 翻訳Mod（eu4dll_translations、yml 145ファイル＋生成フォント32ファイル）を有効にすると、メニュー、Game Browser、国選択画面の全面に日本語が表示されることを実機で確認済み。所有者の環境でも直接起動で日本語表示を確認済み（2026-11-21）。
- 日本語表示の仕組みは3点の組合せである。(1) 生成フォント（Noto Sans CJK JP）とグリフ表のサイドテーブル拡張、(2) 描画・計測経路の復号フック（既定で有効、EU4DLL_ENABLE_DECODE=0 で無効化）、(3) ローカライズ読み込みフック（LocalizeYmlAddKey で値をエスケープ形式のまま辞書へ格納、既定で有効、EU4DLL_LOCALIZE_ESCAPE=0 で無効化）。
- DLL は非EU4プロセスでは何もしない（preload ガード）。Steam 経由・直接起動のどちらでも使える。
- 項目1〜32と2026-11-21夜の追加作業（復号既定化、SetText辞書の実装、読み込みフック、wide path 修正、preload ガード）は全て master へマージ・push 済み。2026-11-22には、読み込みフックの既定有効化とSetText辞書の廃止も master へマージ済み。経緯は progress.md と details/ に記録がある。
